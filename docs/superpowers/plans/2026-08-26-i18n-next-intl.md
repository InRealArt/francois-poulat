# FR/EN Internationalization with next-intl Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the François Poulat / InRealArt landing page bilingual (English default at `/`, French at `/fr`) using `next-intl`, with every hardcoded French string moved into namespaced JSON message files and rendered through next-intl's server/client APIs.

**Architecture:** Introduce `next-intl` routing with `localePrefix: "as-needed"` and `defaultLocale: "en"`. Move the app under `src/app/[locale]/`. Add `middleware.ts` for locale detection/redirect, `src/i18n/routing.ts` + `src/i18n/navigation.ts` + `src/i18n/request.ts` for config, and `messages/en.json` + `messages/fr.json` for all copy. `src/lib/content.ts` keeps only non-textual data (ids, sizes, prices, image paths) keyed by stable `id`s that match message keys. Server Components use `getTranslations`; Client Components (`Header`, `Formats`, `Faq`, `GalleryDetails`, `ReservationModal`) use `useTranslations`.

**Tech Stack:** Next.js 16 (App Router), React 19, TypeScript 5 (strict), Tailwind v4, `next-intl` (new dependency), GSAP (unaffected).

**Spec:** `docs/superpowers/specs/2026-08-26-i18n-next-intl-design.md`

## Global Constraints

- Library: `next-intl` only — no `react-i18next`, no custom context provider.
- Routing: `localePrefix: "as-needed"`, `defaultLocale: "en"` (served at `/`), `locales: ["en", "fr"]` (French at `/fr`).
- No new locales beyond `en`/`fr` in this iteration; message structure must make adding one later a matter of adding a JSON file + entry in `routing.ts`.
- Every string currently hardcoded in JSX (headings, paragraphs, `alt`, `aria-label`, button/link text, form labels) must move to `messages/en.json` / `messages/fr.json`. Exceptions explicitly allowed by the spec: `Footer`'s `socials` labels (brand names, not translated), image `src` paths, `href` URLs, numeric prices/sizes, icon keys.
- `messages/en.json` and `messages/fr.json` must have identical key structure (same namespaces, same keys, same array lengths) — this is checked manually in the final verification task.
- `content.ts` item `id`s (e.g. `"intime"`, `"matieres"`, `"certificate"`) are the join key between data (`content.ts`) and copy (`messages/*.json` under `items.<id>`). Do not rename existing ids.
- No test framework exists in this repo. Verification is `tsc --noEmit`, `next lint`, `next build`, and manual browser checks (documented per task where relevant) — do not introduce a test runner.
- Preserve all existing Tailwind classes, GSAP animation logic, and interactive behavior (carousel drag/autoplay/lightbox, FAQ accordion, modal focus trap, mobile menu) exactly as-is — only the source of text strings and the routing/file layout change.

- [ ] **Step 4: Create `src/i18n/request.ts`**

```typescript
import { hasLocale } from "next-intl";
import { getRequestConfig } from "next-intl/server";
import { routing } from "./routing";

export default getRequestConfig(async ({ requestLocale }) => {
  const requested = await requestLocale;
  const locale = hasLocale(routing.locales, requested)
    ? requested
    : routing.defaultLocale;

  return {
    locale,
    messages: (await import(`../../messages/${locale}.json`)).default,
  };
});
```

      closeButtonRef.current?.focus();

    if (!menuOpen) return;

    function handleTab(event: KeyboardEvent) {
      if (event.key !== "Tab") return;

      const focusable = dialogRef.current?.querySelectorAll<HTMLElement>(
        'a[href], button:not([disabled])'
      );
      if (!focusable || focusable.length === 0) return;

      const first = focusable[0];
      const last = focusable[focusable.length - 1];

      if (event.shiftKey && document.activeElement === first) {
        event.preventDefault();
        last.focus();
      } else if (!event.shiftKey && document.activeElement === last) {
        event.preventDefault();
        first.focus();
